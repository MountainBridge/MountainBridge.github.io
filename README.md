# mountainbridge.github.io

Portfolio site of **Nidhi Verma**, Senior Full Stack Engineer · AI evaluation & reliability.

**Live:** https://mountainbridge.github.io

## What it is
A single hand-built HTML page (no framework, no build step) that shows the same work two ways:

- **The story (light):** who the user is, their journey, the constraints.
- **The system (dark):** the architecture and the evidence that it works.

Drag the sun/moon switch in the hero to slide between the two, or use the switch in the top corner to flip the whole site.

## Details
- Plain HTML, CSS and a little JavaScript in `index.html`
- Follows the visitor's light/dark setting and remembers their choice
- Slider works with mouse, touch and arrow keys; respects reduced-motion settings
- Hosted free on GitHub Pages: every commit to `main` goes live in about a minute
